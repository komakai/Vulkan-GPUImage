## Vulkan-GPUImage

*[中文原文 (Original Chinese README)](README_cn.md)*

A Vulkan-rendered version of GPUImage, implementing a render chain mechanism and recreating many of GPUImage's effects (gradually adding more).

Filter effects were added with reference to this article: [Writing an Android GPUImage with Vulkan Rendering](https://mp.weixin.qq.com/s/gHzuXq-Yil1If1qs_SVXJA)

For more technical implementation details, see the source code~~
